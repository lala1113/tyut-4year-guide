基础篇 · 学业基石

四六级、转专业、评奖评优、挂科警示——这些是所有方向（保研 / 考研 / 考公 / 就业）的“地基”。无论走哪条路，绩点、英语、无挂科都是硬前提。

◆ 全局大学四年时间轴（总览）

把四大方向串成一条主线：大一打基础 → 大二定方向 → 大三拼冲刺 → 大四收成果。各方向细节见对应板块的“四年时间线”。

大一打地基
  • 绩点：每门课奔 85+，高数 / 大物等学分高的课重点拿下
  • 英语：把四级过了（推免 / 就业的硬门槛），大一下或大二上冲六级
  • 规则：搞清综测怎么加分、奖学金怎么评，别到大三才后悔
  • 探索：关注转专业窗口（GPA 排名前 60% 可申请）
大二定方向
  • 保研：稳住专业排名，参加 S / A 级竞赛攒科创分
  • 考研：数学英语打基础，确定目标院校池
  • 考公：了解国考 / 省考 / 选调生区别，提前关注
  • 就业：寒暑假找实习，简历从大二开始攒
大三拼冲刺
  • 保研：5-8月投夏令营、联系导师；9月推免系统填报
  • 考研：进入系统复习，9月大纲发布、10月报名
  • 考公：备考行测申论；10-11月国考、次年省考/选调公告
  • 就业：暑期实习转正机会 + 秋招提前批投递
大四收成果
  • 保研：9月确认推免资格，10月20日前完成接收
  • 考研：12月统考初试，次年2月出分、3-4月复试
  • 考公：国考笔试/面试、省考联考、选调生政审
  • 就业：秋招（9-11月）→ 春招（3-5月）补漏，拿offer后安心做毕设

◆ 挂科 · 重修警示

◆ 高频问答（FAQ）

挂科了还能保研吗？

原则上不能：太原理工推免要求“本科前六学期（五年制前八学期）无不及格课程”，挂科后即使补考 / 重修通过也不计入保研资格。往年细则中仅对专业前 2% 的特殊情况允许“一门补考（或重修）后 ≥ 80 分”的例外，不要赌例外，以当年学院推免细则为准。

综测到底怎么算？

综测 = 基本素质（思想品德 ≥ 42 分、学业成绩 ≥ 60 分、身心素质 ≥ 18 分，三项全合格）+ 能力素质加分（学业、社会工作、学术研究、创新创业、公益服务、对外交流、体育活动、文化艺术、劳动实践、自强自立十类）。各学院有自己的实施细则，入学后找辅导员要本学院细则看一遍。

选调生和普通公务员有什么区别？

选调生是党政领导干部后备人选，定向选调只面向部分重点高校招录（太原理工在列，详见考公板块）；普通公务员通过国考 / 省考统一招录。选调生通常竞争更小、培养路径更明确、要求党员/学生干部等条件，入职后基层锻炼，发展通道一般更优。

四六级没过影响保研吗？

影响：推免基本条件要求全国 CET-4 ≥ 425 分，直博（本博贯通）要求 CET-6 ≥ 425 分；夏令营和预推免中六级 500+ 是重要加分项。建议大一把四级过了、大二把六级过了，别把英语拖到大三。

转专业什么时候能申请？要什么条件？

一般在学期末集中开展（2025-2026 学年为 6-7 月）：2025 级学生 GPA 排名专业前 60% 可申请，可填 2 个志愿，按 GPA 由高到低录取、优先一志愿；专长生、退伍复学、学习困难 / 身体原因特殊生另有通道。详情见本页“转专业政策”。

挂科后绩点怎么算？补考过了还有影响吗？

不及格科目绩点为 0、不得学分；补考 / 重修通过后，绩点 = 考试成绩对应绩点 × 0.6，成绩单注明“重修”。即使高分通过绩点也打折，所以别指望“先挂后补”。

奖学金多久评一次？大概多少钱？

每学期评定一次。优秀学生奖学金：一等奖 ≤ 专业人数 3%（1800 元，学业前 20% + 3 项荣誉）、二等奖 ≤ 10%（1200 元，前 50% + 2 项）、三等奖 ≤ 20%（600 元，前 60% + 1 项）。另有国家奖学金 8000 元 / 年、励志奖学金 5000 元 / 年等。

大二才开始准备考研，来得及吗？

完全来得及，且是很多人的真实起点。关键是把数学、英语提前打基础（这两门拉分最大、最难短期突击），大三暑假前确定目标院校和专业，具体节奏见考研板块“四年时间线”。
