基础篇 · 学业基石

四六级、转专业、评奖评优、挂科警示——这些是所有方向（保研 / 考研 / 考公 / 就业）的“地基”。无论走哪条路，绩点、英语、无挂科都是硬前提。

◆ 全局大学四年时间轴（总览）

把四大方向串成一条主线：大一打基础 → 大二定方向 → 大三拼冲刺 → 大四收成果。各方向细节见对应板块的“四年时间线”。

大一打地基
  • 绩点：每门课奔 85+，高数 / 大物等学分高的课重点拿下
  • 英语：把四级过了（推免 / 就业的硬门槛），大一下或大二上冲六级
  • 规则：搞清综测怎么加分、奖学金怎么评，别到大三才后悔
  • 探索：关注转专业窗口（GPA 排名前 60% 可申请）
大二定方向
  • 保研：稳住专业排名，参加 S / A 级竞赛攒科创分
  • 考研：数学英语打基础，确定目标院校池
  • 考公：了解国考 / 省考 / 选调生区别，提前关注
  • 就业：寒暑假找实习，简历从大二开始攒
大三拼冲刺
  • 保研：5-8月投夏令营、联系导师；9月推免系统填报
  • 考研：进入系统复习，9月大纲发布、10月报名
  • 考公：备考行测申论；10-11月国考、次年省考/选调公告
  • 就业：暑期实习转正机会 + 秋招提前批投递
大四收成果
  • 保研：9月确认推免资格，10月20日前完成接收
  • 考研：12月统考初试，次年2月出分、3-4月复试
  • 考公：国考笔试/面试、省考联考、选调生政审
  • 就业：秋招（9-11月）→ 春招（3-5月）补漏，拿offer后安心做毕设

◆ 高频问答（FAQ）

挂科了还能保研吗？

原则上不能：太原理工推免要求“本科前六学期（五年制前八学期）无不及格课程”，挂科后即使补考 / 重修通过也不计入保研资格。往年细则中仅对专业前 2% 的特殊情况允许“一门补考（或重修）后 ≥ 80 分”的例外，不要赌例外，以当年学院推免细则为准。

综测到底怎么算？

综测 = 基本素质（思想品德 ≥ 42 分、学业成绩 ≥ 60 分、身心素质 ≥ 18 分，三项全合格）+ 能力素质加分（学业、社会工作、学术研究、创新创业、公益服务、对外交流、体育活动、文化艺术、劳动实践、自强自立十类）。各学院有自己的实施细则，入学后找辅导员要本学院细则看一遍。

选调生和普通公务员有什么区别？

选调生是党政领导干部后备人选，定向选调只面向部分重点高校招录（太原理工在列，详见考公板块）；普通公务员通过国考 / 省考统一招录。选调生通常竞争更小、培养路径更明确、要求党员/学生干部等条件，入职后基层锻炼，发展通道一般更优。

四六级没过影响保研吗？

影响：推免基本条件要求全国 CET-4 ≥ 425 分，直博（本博贯通）要求 CET-6 ≥ 425 分；夏令营和预推免中六级 500+ 是重要加分项。建议大一把四级过了、大二把六级过了，别把英语拖到大三。

转专业什么时候能申请？要什么条件？

一般在学期末集中开展（2025-2026 学年为 6-7 月）：2025 级学生 GPA 排名专业前 60% 可申请，可填 2 个志愿，按 GPA 由高到低录取、优先一志愿；专长生、退伍复学、学习困难 / 身体原因特殊生另有通道。详情见本页“转专业政策”。

挂科后绩点怎么算？补考过了还有影响吗？

不及格科目绩点为 0、不得学分；补考 / 重修通过后，绩点 = 考试成绩对应绩点 × 0.6，成绩单注明“重修”。即使高分通过绩点也打折，所以别指望“先挂后补”。

奖学金多久评一次？大概多少钱？

每学期评定一次。优秀学生奖学金：一等奖 ≤ 专业人数 3%（1800 元，学业前 20% + 3 项荣誉）、二等奖 ≤ 10%（1200 元，前 50% + 2 项）、三等奖 ≤ 20%（600 元，前 60% + 1 项）。另有国家奖学金 8000 元 / 年、励志奖学金 5000 元 / 年等。

大二才开始准备考研，来得及吗？

完全来得及，且是很多人的真实起点。关键是把数学、英语提前打基础（这两门拉分最大、最难短期突击），大三暑假前确定目标院校和专业，具体节奏见考研板块“四年时间线”。

01

保研 · 推免

全称“推荐优秀应届本科毕业生免试攻读研究生”。太原理工推免按《太原理工大学推荐优秀应届本科毕业生免试攻读研究生工作管理办法（修订）》执行，本科前六学期综合成绩排名在专业推荐名额内即可申请，近年学校整体保研率约 11.87%。

◆ 四年时间线

大一

打基础：绩点是硬通货

  • 高数、大物等基础课务必高分——推免看的是前六学期综合成绩排名，挂科一票否决（补考通过也不计）
  • 尽早通过英语四级、冲刺六级；英语是推免复试硬性考核项（占 20%）
  • 养成稳定的学习节奏，加入学习型小组互帮互助
大二

稳排名：竞赛科研加分

  • 保持专业排名在推免名额线内，避免出现波动科目
  • 参加数学建模、全国大学生数学竞赛、英语竞赛等认可度高的竞赛，获奖是科创加分项
  • 尝试进实验室/课题组，争取参与科研项目与论文发表（需官方认定证明）
大三上

定目标：摸清政策与院校

  • 研读学院推免实施细则，核对本专业名额与科创成绩答辩要求
  • 锁定目标院校：研招网查招生简章、专业目录、往年录取名单；官网看夏令营安排、师资
  • 关注“3+1+4”本博贯通（直博）与支教团、保资辅导员等专项通道
大三下

夏令营与预推免（5–8月）

  • 5–7月投递目标高校“优秀大学生夏令营”，优秀营员=提前锁定offer
  • 暑期打磨个人材料：成绩单、竞赛证书、论文/科创证明、个人陈述
  • 主动用邮件联系心仪导师，早联系、有礼貌、附简历
大四上

系统填报与复试（9–10月）

  • 9月学院公示推免名单；9月22日前后登录教育部“推免服务系统”填报志愿（专业与本科相同或相近）
  • 复试构成参考：思想政治与品德 + 专业知识与能力（50%）+ 综合素质（30%）+ 外语水平（20%）
  • 10月20日前完成全部接收流程，公示无异议后报省招考中心审核

02

考研 · 统考

全国硕士研究生统一招生考试是太原理工本科生深造的主要通道之一。2023届本科毕业生升学 2691 人、占 35.02%。考研 = 信息战 + 持久战，按年级拆解任务，逐步推进。

◆ 四年时间线

大一

夯地基：数学与英语先行

  • 高数认真学：建议跟武忠祥 / 宋浩网课打底，同步刷《基础过关660题》，错题及时复盘
  • 每天坚持背单词、精读长难句——英语是长期积累的科目，突击无效
  • 保持绩点，给自己留一条“后悔保研名额”的后路
大二

定方向：院校专业调研

  • 结合兴趣与就业，圈定 2–3 所目标院校；查近三年录取数据，设定合理的初试目标分数
  • 把总分拆到各科目（如政治 70、英语一 65、数学 110、专业课 120）
  • 关注目标院校是否自命题、单科线要求；跨专业考生提前旁听基础课
大三上（3月）

启动系统复习

  • 数学：3–8月基础阶段（过课本 + 660题）→ 9–10月强化题型训练
  • 英语：单词 + 阅读精读精翻；政治：7月起看基础课、刷肖1000选择题
  • 专业课：吃透参考书，整理名词解释/简答/论述背诵笔记，至少记忆三轮
大四上

报名与冲刺（9–12月）

  • 9月预报名 → 10月正式报名 → 12月打印准考证
  • 11–12月：政治刷肖四肖八选择题、肖四分析题背熟；英语整套真题模拟
  • 12月下旬初试：行百里者半九十，最后一个月拼的是坚持
大四下

复试与调剂（2–5月）

  • 2月出分 → 3月国家线/院校线公布 → 复试（笔试+面试，比例约 1:1.4）
  • 复试务必重视：一志愿与调剂一起排名录取，面试要练表达、心态放平
  • 未过线及时关注调剂系统，多渠道搜集信息

03

考公 · 选调

公务员与选调生是太原理工学子重要的去向之一：山西省每年面向太原理工大学定向选调优秀毕业生（如2024年选调 588人），化学工程与技术学科毕业生可报省直单位定向选调。应届身份是最大优势窗口。

◆ 四年时间线

大一

定身份：专业与政治面貌

  • 很多岗位限“中共党员/预备党员”——尽早递交入党申请、积极向党组织靠拢
  • 学好专业：选调岗位多要求专业对口（工学门类覆盖大量岗位）
  • 熟悉国考/省考/选调三条路径的区别，明确兴趣方向
大二

攒履历：学生工作与实践

  • 担任班干部、学生会/社团骨干——选调生选拔重视学生干部经历与政治素质
  • 参加暑期社会实践、志愿服务，积累可写入简历的经历
  • 关注《山西选调生管理暂行办法》与学校就业信息网公告
大三

系统备考：行测 + 申论

  • 行测模块化学习（言语/判断/数量/资料/常识），每模块专项刷题找薄弱点
  • 申论积累素材：学习强国、人民日报评论、新闻联播；真题当例子用
  • 做整套真题务必掐时间，练习时间分配与取舍；选岗优先“限专业/限应届”岗位
大四上

国考与选调（10–12月）

  • 10–11月：国考报名与笔试（行测+申论）
  • 11–12月：山西省定向选调报名（往年12月报名、次年1月笔试《综合能力测试》），需学院党组织盖章推荐
  • 同阶段可关注各省选调：太原理工化学工程与技术等学科在山西等多省选调名单内
大四下

省考与面试政审（2–6月）

  • 2–3月：各省省考报名与笔试（山西省考通常上半年举行）
  • 面试：反模板化、就事论事，结合岗位谈自己的看法；模拟练习车轮战
  • 体检、政审、公示——走完全程，静候录用

直接就业

太原理工毕业生就业以制造业（22.29%）、教育（18.09%）、信息技术服务业（15.39%）为主，国企央企签约占比约 37%，去向集中在北京（23%）、太原（19%）、上海（9%）。抓住秋招黄金期，offer 不请自来。

◆ 四年时间线

大一

自我探索：职业规划课

  • 认真上学校“我与大学 / 我与社会 / 我与职业 / 我与未来”系列生涯规划课程
  • 完成自我探索：兴趣、价值观、能力定位，初步确定职业方向
  • 加入学生组织锻炼沟通协作，这是企业最看重的软素质
大二

职业体验：简历从0到1

  • 参加求职训练营、简历大赛、生涯团辅（学校年均组织 3 万余人次参与）
  • 争取暑期实习 / 校企联合项目，职业环境体验是最好的老师
  • 动手写第一版简历，边经历边更新
大三

实习冲刺：秋招提前批

  • 暑假进入目标行业核心岗位实习，争取转正机会（提前批锁定 offer）
  • 系统学习结构化面试 / 无领导小组讨论，模拟演练
  • 关注学校就业信息网与“校园招聘会”，锁定重点行业、重点企业、重点项目
大四上

秋招黄金期（9–11月）

  • 中国建筑、国家电网、中铁、中车、万华化学等央企国企每年大量招聘太原理工毕业生
  • 线上（学校就业平台、智联/前程无忧）+ 线下（校园宣讲会/双选会）双线投递
  • 拿 offer 后认真比选：城市、行业、岗位、发展通道，别只看薪资
大四下

春招补录与签约（3–6月）

  • 春招（3–5月）补录：考研失利 / 秋招未果的同学的第二窗口
  • 签约：注意三方协议条款与违约金，确认户口、五险一金、试用期安排
  • 办理就业手续盖章：提前联系学校招生与就业工作部值班老师
